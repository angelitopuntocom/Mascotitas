# 🐾 Mascotitas

Proyecto de tienda de mascotas desarrollado en Java con Programación Orientada a Objetos (POO) y conexión a base de datos MySQL. Implementado desde consola con múltiples funcionalidades.

## 📦 Funcionalidades del sistema

- Alta de clientes y mascotas
- Alta/baja de personal (veterinarios, asistentes, gerente)
- Registro de citas a domicilio
- Adopción y devolución de mascotas
- Gestión de paquetes (baño, corte, etc.)
- Pagos y consultas
- Escritura de citas a archivo
- Múltiples sucursales con Enum `Sucursal`

## Requisitos

- NetBeans IDE (versión 12+)
- JDK 8 o superior
- MySQL (con Workbench o servidor local)
- Driver JDBC para MySQL (ya incluido o manual)
